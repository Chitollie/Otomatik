# Otomatik 1.0.0

Interface Python/PySide6 noir + bleu.

Fonctions incluses : AutoFish configurable, AntiAFK S puis Z toutes les 20 minutes, vérification de mises à jour GitHub avec SHA-256, structure prête pour Discord OAuth et publication administrateur.

Configuration GitHub dans `app/config.py`.

Installation : `pip install -r requirements.txt`

Compilation Windows : lancer `build.bat` pour obtenir `dist\Otomatik.exe`.

Le compte Discord administrateur prévu est `765306791093076058`. Pour publier depuis l'application, le jeton GitHub doit rester local et ne doit jamais être intégré dans l'EXE.
